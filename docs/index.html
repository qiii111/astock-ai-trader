隐私保护

此网页的代码公开，但你的持仓、成本、成交记录不应公开。数据仅在登录后从 Supabase 按用户权限读取。实际买卖由你自行在证券 App 执行。

首次使用需要配置 Supabase 的 Project URL 和 publishable / anon 公钥。不要填写数据库密码、service_role 或 secret key。

连接私人数据库

连接参数保存在当前浏览器的 localStorage，关闭网页后仍可使用；它们是公开客户端配置，不是数据库管理密钥。请勿在共享设备上使用。
